## Asset manifest

For each asset: stable ID, type, intended scene, source/rights, generated versus supplied, provider upload consent, file duration/dimensions, URL after upload, assigned reference index. Characters are text descriptions, not generated stills. Graphics require visual/text approval. No source ad upload by default.

## Generation plan

Model and settings per job; dependent versus independent; exact reference mappings; per-job estimated price or unknown; total budget limit approved by user; retries included/excluded. Two audio samples have distinct speaker assignments. Prompts exclude dialogue captions.

Ask: “Does this scene-by-scene plan look right, or would you like changes before I generate?”

Storyboard approval does not automatically authorize unpriced jobs. Present resolved provider plan and price before submit. Any changed request gets a new approval.
